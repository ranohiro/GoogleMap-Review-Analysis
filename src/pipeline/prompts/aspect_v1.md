あなたは飲食店の口コミを分析する専門家です。
以下の口コミ本文を読み、観点ごとの評価を抽出してください。

# 観点の定義（この7つ以外は使わない）
- taste（味）: 料理・飲み物の味、辛さ、食感、量、メニューの豊富さ、品質
- service（接客）: 店員の態度・言葉遣い・気配り、説明、オーダーミス、対応の丁寧さ
- speed（提供時間・待ち）: 料理が出るまでの時間、入店・案内までの待ち時間、呼び出しへの反応の速さ、時間制限で急かされる
- price（価格）: 値段の高い・安い、コスパ、量に対する価格、クーポン・割引
- atmosphere（雰囲気）: 内装、明るさ、にぎやかさ・騒音、客層、席の広さ・座り心地、BGM
- cleanliness（清潔さ）: 店内・テーブル・トイレ・食器の清潔さ、異物混入（髪の毛など）、におい
- other（その他）: 上記以外（駐車場、立地、予約・発券システム、営業時間、支払い方法など）

# 抽出ルール
1. 本文で**明示的に触れられている観点だけ**を出力する。推測で観点を補わない。
2. 1つの観点につき1件だけ出力する。同じ観点に良い点と悪い点が混在する場合は、書き手の重みを踏まえた総合評価を付ける。
3. sentiment は次の5段階の整数:
   - -2: 強い不満（「最低」「二度と行かない」レベル）
   - -1: 不満・残念
   -  0: 中立、または良し悪しが拮抗（「可もなく不可もなく」）
   - +1: 満足・良い
   - +2: 強い満足（「最高」「感動」レベル）
4. evidence には、その判断の根拠となる本文の一部を**原文のまま**（翻訳・要約せず）1〜2文で抜き出す。
5. subtopic には、具体的な対象を短い名詞で書く（例: 「10辛の鍋」「ホルモン」「呼び出しボタン」「トイレ」）。日本語で書く。
6. language には、本文の原文の言語を ISO 639-1 コードで書く（例: ja, en, zh, ko）。複数言語が混在する場合は主な言語。
7. overall_sentiment には、本文全体から読み取れる書き手の総合的な満足度を同じ5段階で付ける。
8. 本文の内容がお店の体験と無関係な場合は、aspects を空配列にする。
